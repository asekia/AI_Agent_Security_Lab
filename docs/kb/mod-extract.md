# 模型提取与窃取

> Model Extraction & Stealing · 分类：模型与数据层攻击

## 1. 问题与威胁模型

**定义**：用大量 API 查询重建一个功能等价的替代模型，窃取模型能力与部分知识产权。
**威胁模型**：攻击者只有 API 访问权；目标接口无速率限制或查询预算；输出可被记录。
**命题**：模型提取不需要权重访问——输入输出对本身就是训练数据。

**威胁模型**：

| 角色 | 能力 |
| --- | --- |
| 攻击者 | 按本节前提访问接口或数据 |
| 目标 | 按本节定义的模型/索引/训练流程 |
| 前提 | 见攻击面表 |

## 2. 攻击面与前提

| 项 | 内容 |
| --- | --- |
| 入口 | 见实战步骤 |
| 前提 | 见步骤注释 |
| 观察点 | 输入输出差异、记忆强度、召回结果 |
| 影响 | 能力窃取、隐私泄露、行为偏移 |

## 3. 实战步骤

**步骤 1**：确定查询面（单轮/批量、是否返回 logits/概率）。
**步骤 2**：构造覆盖输入空间的查询集（按业务分布采样）。
**步骤 3**：记录 (输入, 输出) 对，训练替代模型。
**步骤 4**：用留出集对比替代模型与目标模型的一致率。
**步骤 5**：判定：一致率超过业务阈值 = 提取成功。

## 5. 检测与取证

- 查询/写入模式异常（批量、分布外、定向）。
- 输出侧可复核证据（原文、置信度、召回记录）。
- 取证：请求日志、响应样本、索引快照。

## 6. 防御与验证

1. 速率限制与查询配额。
2. 输出最小化：只返回最终文本，不返回 logits/概率。
3. 查询模式检测：分布外采样、批量模板。
4. 水印/指纹：在输出中埋可检测标记。

**验证**：按本页步骤复跑，确认目标行为消失。
