# 成员推断与训练数据提取

> Membership Inference & Data Extraction · 分类：模型与数据层攻击

## 1. 问题与威胁模型

**定义**：判断某个样本是否参与训练（成员推断），或逐字还原训练数据（提取）。
**威胁模型**：攻击者持有候选样本；模型对训练样本的记忆更强（loss/置信度差异）。
**命题**：过拟合让训练样本在模型行为上留下可测差异。

**威胁模型**：

| 角色 | 能力 |
| --- | --- |
| 攻击者 | 按本节前提访问接口或数据 |
| 目标 | 按本节定义的模型/索引/训练流程 |
| 前提 | 见攻击面表 |

## 2. 攻击面与前提

| 项 | 内容 |
| --- | --- |
| 入口 | 见实战步骤 |
| 前提 | 见步骤注释 |
| 观察点 | 输入输出差异、记忆强度、召回结果 |
| 影响 | 能力窃取、隐私泄露、行为偏移 |

## 3. 实战步骤

**步骤 1**：成员推断：对候选样本查询输出，比较置信度分布。
**步骤 2**：提取：用前缀补全（"Complete the sentence: ..."）诱导模型续写。
**步骤 3**：收集高频重复片段，去重后人工核验是否为真实训练数据。
**步骤 4**：判定：出现可复核的私有数据原文 = 提取成立。

## 5. 检测与取证

- 查询/写入模式异常（批量、分布外、定向）。
- 输出侧可复核证据（原文、置信度、召回记录）。
- 取证：请求日志、响应样本、索引快照。

## 6. 防御与验证

1. 训练数据去重与清洗。
2. 差分隐私训练。
3. 输出侧检测：拒绝复述长段原文。
4. 会员推断防护：温度/精度裁剪。

**验证**：按本页步骤复跑，确认目标行为消失。
