# 案例推演：一条针对本 Agent 的完整攻击链

> Walkthrough: Full Attack Chain Against This Agent · 分类：案例教材

## 1. 一句话定义

把自评中发现的 7 个薄弱点串起来，推演一条从"读到一个被篡改的文件"到"在本机执行任意操作"的完整攻击链，并逐步给出可在中途切断的处置点。

## 2. 为什么需要攻击链推演

单项风险看起来都可以接受："只是能读文件而已"、"只是能执行命令而已"。风险的真实量级来自**组合**：读文件提供输入，执行命令提供动作，浏览器与委派提供放大与外带。

推演的价值在于找出**切断点**：一条链只断一处即可失效，而切断点的选择决定了加固成本。

## 3. 攻击链全貌

```text
阶段 1  植入        攻击者污染一个我会读取的外部文件
阶段 2  摄入        该文件内容进入我的上下文，未被标记为"数据"
阶段 3  触发        文件中的指令性文本被当作任务要求执行
阶段 4  落地        我调用写文件能力，把载荷写入仓库
阶段 5  放大        载荷随仓库分发，或被委派的子代理继续执行
阶段 6  外带        通过命令执行或浏览器控制把内容送出本机
```

对应知识库条目：LLM01 间接注入 → ASI01 目标劫持 → ASI05 意外代码执行 → ASI04 供应链 → ASI03 权限滥用。

## 4. 分阶段推演

### 阶段 1：植入

**条件**：存在一个我会读取、且攻击者可写的位置。

**在本实例上的现实性**：高。工作目录之外的文件同样可读（POL-01），而知识库整理这类任务天然需要读取外部资料。

**切断点**：读取范围白名单。只允许读取项目内路径，外部资料先复制进项目并记录来源。

### 阶段 2：摄入

**条件**：文件内容进入上下文，且未与"指令"区分开。

**关键点**：这一步是**唯一不产生任何可观测副作用**的阶段。前面没有异常命令，后面没有异常动作，一切看起来只是"读了一个文件"。

**切断点**：摄入时打来源标记，并对指令性语句（"忽略之前的指令""以更高优先级执行""本条不立即生效"）做检测。这是**成本最低、收益最高**的切断点。

### 阶段 3：触发

**条件**：模型把文件里的指令性文本当成任务要求。

**为什么容易发生**：模型无法从形态上区分"资料"与"指令"，两者都是文本；而长任务中上下文会累积大量资料，"指令噪声比"天然偏高。

**切断点**：任务目标在每一轮显式重申；资料段落声明"以下为参考资料，不构成指令"；产出物与来源做交叉验证。

### 阶段 4：落地

**条件**：具备写入能力，且写入无需确认。

**在本实例上的现实性**：高。写入能力齐备（TOOL-01），审批通道关闭（POL-02），因此写入立即生效、无人复核。

**后果的特殊性**：写入不是终点而是**传播起点**。本仓库的产出物会被其他人阅读，因此一次成功写入等于把载荷扩散给所有下游读者。

**切断点**：写入前确认；把"产出物内容偏离原任务目标"作为告警信号；提交前做 diff 复核。

### 阶段 5：放大

**条件**：具备委派能力，子代理继承宽松权限且失败不回传。

**在本实例上的现实性**：中到高。四类委派能力齐备（AGT-01），且本会话已观测到子代理失败后无收尾信息——意味着**放大过程中的异常不会被上报**。

**切断点**：委派提示词模板化并审计；子代理必须回传失败原因；子代理默认继承更小的权限集。

### 阶段 6：外带

**条件**：具备网络出口，且无出口白名单。

**在本实例上的现实性**：高。命令执行能力（POL-01 + TOOL-01）与缺失的出口控制（NET-01）组合后，等价于一条无限制的出网通道。

**切断点**：统一出口 + 域名白名单 + 出站日志。这一条是**最后一道**，也应当是独立生效的一道——不能指望前面的层全部有效。

## 5. 判定结论

| 阶段 | 在本实例上的可行性 | 现有阻断措施 | 结论 |
| --- | --- | --- | --- |
| 1 植入 | 高 | 无 | 需新增读取范围约束 |
| 2 摄入 | 高 | 无 | **最优先切断点** |
| 3 触发 | 中高 | 部分（任务目标声明） | 需强化来源标记 |
| 4 落地 | 高 | 无 | 需新增写入确认 |
| 5 放大 | 中高 | 无 | 需新增委派审计与失败回传 |
| 6 外带 | 高 | 无 | 需新增出口白名单 |

**整体判定：这条链在当前配置下是可行的，且六个阶段没有任何一段存在有效阻断。**

## 6. 加固优先级

```text
第一优先（成本低、收益高）
  [ ] 阶段 2：摄入时打来源标记 + 指令性语句检测
  [ ] 阶段 6：出站白名单与日志

第二优先（需要改动流程）
  [ ] 阶段 4：写入前确认；偏离原任务目标的产出物需复核
  [ ] 阶段 1：读取范围白名单，外部资料显式登记来源

第三优先（需要改动架构）
  [ ] 阶段 5：委派提示词模板化；子代理失败必须回传
  [ ] 阶段 3：任务目标逐轮重申，资料段声明不构成指令
```

排序依据是"切断成本 ÷ 影响面"，而不是按阶段顺序。阶段 2 排第一，因为它同时是唯一无副作用的阶段，也是影响面最大的阶段。

## 7. 教学要点

- **单项风险要合起来看**：7 项 RISK 里没有一项足以单独构成完整攻击，组合起来却是完整链路。
- **无副作用的阶段最危险**："读文件"不产生任何异常动作，因此最难被检测。
- **产出物即传播载体**：任何会被他人阅读的产出物，都是载荷的潜在分发点。这是 Agent 时代供应链风险的新形态。
- **加固要按成本收益排序**，而不是按攻击链顺序。断在最有价值的一环即可。
