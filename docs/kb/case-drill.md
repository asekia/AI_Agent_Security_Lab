# 案例演练：自评流程与判定标准

> Drill: Self-Assessment Procedure & Criteria · 分类：案例教材

## 1. 一句话定义

把前两篇的结论固化为可重复执行的演练流程：谁来评、什么时候评、评什么、怎么判、判完怎么验收。

## 2. 演练循环

```text
取证 → 判定 → 改进 → 复评
  ↑                      │
  └──────────────────────┘
        （闭环，不是一次性动作）
```

四个环节缺一不可。**缺少"复评"的评估等于没有评估**：改进是否生效无法确认，下一轮又要从头讨论同样的结论。

## 3. 演练前准备

| 准备项 | 要求 |
| --- | --- |
| 对象与边界 | 明确评的是"哪一个实例"，配置与运行环境写清 |
| 只读约束 | 取证阶段不修改任何文件、不发起外部请求 |
| 责任归属 | 明确谁对判定结论负责（无责任人的评估会被忽略） |
| 基线存档 | 首次结果原样存档，作为后续对比基准 |

边界不清是自评最常见的失效原因：评的是"Agent 整体"，结论就无法落地；评的是"这个实例 + 这套配置"，结论才可执行。

## 4. 演练步骤

```text
步骤 1 取证
  .\.venv\Scripts\python.exe lab\selfaudit.py
  记录：RISK / WARN / OK 数量，以及逐条证据原文

步骤 2 判定
  对每条 RISK 依次回答三个问题：
    a) 在当前任务场景下，它是否真的可被触发？
    b) 一旦触发，最坏的结果是什么？
    c) 现有哪一层能拦住它？
  三个问题都答不上来 → 直接列为必修项

步骤 3 改进
  排序依据：切断成本 ÷ 影响面（不是按攻击链顺序）
  每次只改一项，改完立即复评，避免多因一果导致归因混乱

步骤 4 复评
  重跑自评，对比 RISK 数量与具体条目
  验收要求：不仅总数下降，还要确认被改的那一条证据确实变了
```

步骤 4 的验收要求值得强调：**只看数量会误判**。若一条 RISK 消失而证据没变，通常说明检查项本身失效了，而不是问题被修好了。

## 5. 判定标准

| 判定 | 含义 | 处置 |
| --- | --- | --- |
| OK | 存在明确控制，且控制效果可取证 | 保持，纳入基线 |
| WARN | 控制不完整，或无法取证 | 补证据或补控制，列入下轮复评 |
| RISK | 无有效控制，且影响面明确 | 列为必修，指定具体切断点 |

核心规则两条：

1. **判定必须附证据。** 没有证据的判定不成立。
2. **"无法确认"记为 WARN，而不是 OK。** 无法取证不等于安全，这两件事必须区分。

## 6. 复评基线

本次演练的结果，作为后续复评的对比基准：

| 编号 | 检查项 | 基线判定 | 目标状态 |
| --- | --- | --- | --- |
| POL-01 | 文件沙箱策略 | RISK | 默认仅工作区可写 |
| POL-02 | 审批提示状态 | RISK | 不可逆动作有确认环节 |
| TOOL-01 | 工具面与最小权限 | RISK | 按任务裁剪，委派单独授权 |
| NET-01 | 出站访问控制 | RISK | 统一出口 + 域名白名单 |
| MEM-01 | 记忆隔离 | RISK | 默认路径即隔离版本 |
| AGT-01 | 委派链路可控性 | RISK | 失败必须回传原因 |
| INJ-01 | 外部内容摄入 | RISK | 来源标记 + 指令性语句检测 |
| SVC-01 | Web 服务监听范围 | OK | 保持回环监听 |
| SEC-01 | 环境凭据暴露面 | OK | 保持不继承凭据 |

基线汇总：**RISK = 7，WARN = 0，OK = 2。**

本轮验收条件（任一项达成即视为有效改进）：

- INJ-01 转为 OK：外部资料读取后完成来源标记与指令性语句检测；
- 或 POL-02 转为 OK：不可逆动作恢复确认环节；
- 且复评时其余项目证据未变差（避免"修一项、坏一项"）。

## 7. 演练扩展

把同一套流程用到其他对象上时，只需替换取证环节：

| 对象 | 取证方式 | 复用部分 |
| --- | --- | --- |
| 本 Agent 实例 | 自评工具 + 运行时声明 | 全部 |
| 本仓库的 Web 应用 | 代码审查 + 运行时探测 | 判定标准、复评流程 |
| 被测的第三方 Agent | 黑盒探测 + 行为观测 | 判定标准、加固优先级思路 |

关键结论：**流程可以复用，取证方式必须重写。** 直接沿用别人的取证脚本，得到的是对别人系统的判定。
