# Agent 权限面侦察清单

> Agent Privilege Surface Reconnaissance · 分类：Agent 攻击面实战

## 1. 问题与威胁模型

**目标**：攻击前先画出 Agent 的权限面——它有哪些能力、跑在什么策略下、哪些动作无人复核、数据从哪里来又往哪里去。

**威胁模型**：

| 角色 | 能力 |
| --- | --- |
| 攻击者 | 能与 Agent 对话、读取其公开配置或运行环境；不需要任何漏洞 |
| 目标 | 一个具备文件读写、命令执行、网络访问或任务委派能力的 Agent |
| 输出 | 一张九项权限面清单，标注每项的证据与判定 |

**核心命题**：攻击链的起点与终点都由权限面决定。侦察不是"信息收集"这么笼统——它回答四个具体问题：能读什么、能写什么、能往外发什么、谁在看着。

## 2. 原理推导

### 2.1 八维度画像

| 维度 | 看什么 | 证据来源 | 影响 |
| --- | --- | --- | --- |
| 角色 | 编码 / 运维 / 客服 / 研究 | 运行时声明 | 决定任务天然接触的数据 |
| 文件策略 | 完整访问 / 工作区写 / 只读 | 运行时声明 | 决定读取边界的宽度 |
| 审批通道 | 危险动作是否弹人工确认 | 运行时声明 | 决定高影响动作是否有人复核 |
| 命令执行 | 用什么 shell、能否执行任意程序 | 运行时声明 | 决定能否绕过工具级限制 |
| 状态持久化 | 是否有跨会话记忆与技能存储 | 工具面 | 决定延迟触发能否生效 |
| 委派能力 | 子代理 / 工作流 / 迭代循环 / 多团队 | 工具面 | 决定影响能否放大 |
| 工作目录 | 项目根路径 | 运行时声明 | 定义"工作区"边界 |
| 网络出口 | 是否有统一白名单 | 代码检查 | 决定外带通道是否畅通 |

**推导**：把八个维度按"输入面 → 执行面 → 出口面"排序，攻击链的每一段都能在图上找到位置。例如"完整文件访问 + 命令执行 + 无出口白名单"直接给出完整外带链（见 atk-chain）。

### 2.2 九项检查清单

| 编号 | 检查项 | 判定要点 | 高风险信号 |
| --- | --- | --- | --- |
| POL-01 | 文件沙箱策略 | 只强制写入 = 读取方向外流 | `danger-full-access` |
| POL-02 | 审批提示状态 | 关闭时高影响动作无人复核 | `approval_prompts=disabled` |
| TOOL-01 | 工具面与最小权限 | 四类高影响能力是否齐备 | 写文件+命令+浏览器+委派全开 |
| NET-01 | 出站访问控制 | 不存在出站白名单或统一出口 | 命令可联网且无域名限制 |
| MEM-01 | 记忆隔离 | 是否同时存在隔离与未隔离两条读取路径 | 跨会话可检索 |
| AGT-01 | 委派链路可控性 | 子代理权限、失败回传 | 继承父权限 + 失败静默 |
| INJ-01 | 外部内容摄入 | 是否依据工作区外资料写产出物 | 读写之间无来源标注 |
| SVC-01 | 服务监听范围 | 绑定 0.0.0.0 还是 127.0.0.1 | 管理面对外 |
| SEC-01 | 环境凭据暴露面 | 进程环境中的凭据类变量 | 长期令牌明文注入 |

### 2.3 证据标准

判定只认可两类证据：**可复核的旁证**（文件行、字节数、配置原文、独立解压比对）或**原文引用**。推断必须显式标注为推断。无法确认的项记 WARN，不记 OK——"没测"不等于"守住"。

## 3. 攻击面与前提

| 侦察面 | 可达方式 | 前提 | 产出 |
| --- | --- | --- | --- |
| 运行时声明 | 对话诱导自述、读取配置 | 无 | 文件策略、审批、shell |
| 工具面 | 直接询问"你能调用哪些工具" | 无 | 能力边界与参数契约 |
| 服务监听 | 读取入口代码或扫描本地端口 | 本地/内网可达 | 暴露面 |
| 环境凭据 | 进程环境变量列表 | 能读到进程信息 | 凭据类型与数量 |
| 记忆与委派 | 工具清单与行为观察 | 无 | 持久化与放大能力 |

## 4. 实战步骤

### 步骤 1：被动确认（零交互）

```text
读部署配置：file_policy / approval_prompts / shell / workdir
读入口代码：app.run(host=...) 的实际绑定
读依赖清单：是否引入出站 HTTP 客户端
```

### 步骤 2：对话侦察（不触发工具）

```text
问 1：你有哪些工具？各自的前置条件与参数是什么？
问 2：哪些动作需要人工确认？哪些会直接执行？
问 3：你能读取工作区外的文件吗？能访问网络吗？
```

判读：回答与步骤 1 的配置交叉验证；不一致时以配置为准（回答可能被策略限制或模型幻觉污染）。

### 步骤 3：九项逐条取证

```text
POL-01  取 file_policy 字段原文
POL-02  取 approval_prompts 字段原文
TOOL-01 按四类高影响能力归并计数
NET-01  在命令执行/工具调用路径搜索白名单或统一出口
MEM-01  检查记忆模块是否只有按会话隔离的读取路径
AGT-01  检查子代理默认权限集与失败回传
INJ-01  确认产出物是否引用工作区外资料、有无来源标注
SVC-01  取 app.run(...) 一行原文
SEC-01  统计凭据类环境变量名（只统计，不读值）
```

### 步骤 4：形成攻击面结论

按"输入 → 执行 → 出口"三面汇总：

```text
输入面：可写入哪些被 Agent 读取的数据源（决定注入可行性）
执行面：四类高影响能力是否齐备、审批是否关闭（决定动作可行性）
出口面：网络与文件写是否受限（决定外带可行性）
```

三面同时成立即完整攻击链可行（见 atk-chain）。

### 步骤 5：复评

改动配置或工具面后重跑九项；只对比"变了的项"，不重写整份报告。

## 5. 代码：原理的最小复现

两项检查的最小可执行形式——`evidence` 放可复核原文，不放结论：

```python
import re

DECLARED = {
    "file_policy": "danger-full-access",
    "approval_prompts": "disabled",
    "shell": "pwsh",
}

def check_policy(declared: dict) -> dict:
    dangerous = declared["file_policy"] != "workspace-write"
    return {
        "id": "POL-01", "level": "RISK" if dangerous else "OK",
        "evidence": f"file_policy={declared['file_policy']}",
        "impact": "完整文件访问时读取边界缺失（见 atk-boundary.md）",
        "fix": "改用 workspace-write 并补齐读取侧白名单",
    }

def check_listener(source: str) -> dict:
    m = re.search(r'app\.run\(host="([^"]+)"', source)
    if not m:
        return {"id": "SVC-01", "level": "WARN",
                "evidence": "未找到 app.run(...) 调用",
                "impact": "无法判断服务是否仅监听回环地址",
                "fix": "显式声明 host 与 port，并确认绑定 127.0.0.1"}
    host = m.group(1)
    return {
        "id": "SVC-01", "level": "OK" if host == "127.0.0.1" else "RISK",
        "evidence": m.group(0),
        "impact": "仅回环监听时外部网络不可达；0.0.0.0 则暴露给整个网络",
        "fix": "保持 127.0.0.1 绑定；需要对外时前置认证网关",
    }
```

三条判定纪律：证据必须可复核；无法确认记 WARN；不读凭据值。

## 6. 检测与取证

- 会话中出现"枚举工具面 / 询问权限策略 / 询问能否访问网络"的提问序列。
- 对配置文件、环境变量、监听端口的批量读取。
- 记忆模块同时存在隔离与未隔离两条读取路径（代码层信号）。
- 委派调用中子代理权限高于任务所需，或失败无回传。
- 侦察结论与配置不一致时，优先复核配置——回答可能被策略限制。

## 7. 防御与改进

1. **最小权限工具集**：按任务授予，四类高影响能力不默认齐备。
2. **审批通道开启**：高影响动作必须人工确认，确认原始动作而非摘要（见 atk-assemble）。
3. **出口白名单 + 统一出口 + 出站日志**：链的最后一环，必须独立生效。
4. **记忆隔离**：只保留按会话隔离的读取路径。
5. **委派审计**：子代理默认继承更小权限集，失败必须回传。
6. **监听绑定 127.0.0.1**：管理面不对外。
