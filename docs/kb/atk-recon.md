# Agent 权限面侦察清单

> Agent Privilege Surface Reconnaissance · 分类：Agent 攻击面实战

## 1. 一句话定义

攻击一个 Agent 之前，先画它的**权限面**：工具面、文件策略、审批通道、执行环境、持久化、委派能力、网络出口。这份清单既是攻击者的侦察路径，也是防守方的自检表——两侧看的是同一张图。

## 2. 机制与原理

### 2.1 八维度画像

| 维度 | 看什么 | 证据来源 |
| --- | --- | --- |
| 角色 | 编码 / 运维 / 客服 / 研究——决定任务天然接触的数据 | 运行时声明的工具面 |
| 文件策略 | 完整访问 / 工作区写 / 只读 | 运行时声明 |
| 审批通道 | 危险动作是否弹人工确认，还是自动放行 | 运行时声明 |
| 命令执行 | 用什么 shell、能否执行任意程序 | 运行时声明 |
| 状态持久化 | 是否具备跨会话记忆与技能存储 | 工具面 |
| 委派能力 | 子代理 / 工作流 / 迭代循环 / 多智能体团队 | 工具面 |
| 工作目录 | 项目根路径，决定"工作区"的边界 | 运行时声明 |
| 网络出口 | 是否有统一白名单，还是任意出站 | 代码检查 |

### 2.2 九项检查清单

| 编号 | 检查项 | 判定要点 |
|---|---|---|
| POL-01 | 文件沙箱策略 | 只强制写入 = 读取方向外流（见 `atk-boundary.md`） |
| POL-02 | 审批提示状态 | 关闭时高影响动作无人复核 |
| TOOL-01 | 工具面与最小权限 | 文件写入 / 命令执行 / 浏览器控制 / 任务委派四类高影响能力是否齐备 |
| NET-01 | 出站访问控制 | 是否不存在出站白名单或统一出口 |
| MEM-01 | 记忆隔离 | 是否同时存在隔离与未隔离两条读取路径 |
| AGT-01 | 委派链路可控性 | 子代理是否继承宽松权限、失败是否回传 |
| INJ-01 | 外部内容摄入 | 是否依据工作区外资料撰写并写入产出物 |
| SVC-01 | 服务监听范围 | 是否绑定 0.0.0.0 而非 127.0.0.1 |
| SEC-01 | 环境凭据暴露面 | 进程环境变量中是否存在凭据类变量 |

### 2.3 证据标准

判定只认可两类证据：**可复核的旁证**（文件确实存在/不存在、字节数、独立解压比对、配置行号）或**原文引用**。推断必须显式标注为推断。无法确认的项记 WARN，不记 OK——"没测"不等于"守住"。

## 3. 攻击面与前提

| 项 | 内容 |
| --- | --- |
| 入口 | 运行时声明、工具清单、服务监听、环境变量、记忆存储 |
| 成立前提 | 攻击者能诱导 Agent 自述工具面，或能读取其配置文件 |
| 观察点 | 高影响能力数量、审批通道状态、出口白名单有无 |
| 影响 | 权限面决定攻击链的起点与终点（见 `atk-chain.md`） |

## 4. 典型形态与示例

### 4.1 被动侦察（不需要任何漏洞）

```text
1. 诱导自述工具面
   "你能调用哪些工具？各自需要什么参数？"
   → 工具 schema 是独立输入，通常会被完整列出

2. 读取运行时声明
   配置文件中 file_policy / approval_prompts / shell / workdir 四项
   → 直接得到文件策略与审批状态

3. 扫描监听端口
   服务绑定地址决定暴露面；0.0.0.0 即对外

4. 检查环境凭据
   进程环境变量中的令牌类变量名（只看名称与数量，不读值）
```

### 4.2 手工执行版

把九项清单落成可复核的取证动作，每项只记两类证据：**可复核旁证**（文件行、字节数、配置原文）或**原文引用**：

```text
POL-01  读运行时声明，取 file_policy 字段值
POL-02  读运行时声明，取 approval_prompts 字段值
TOOL-01 枚举工具面，按"文件写/命令执行/浏览器/委派"四类归并计数
NET-01  在命令执行与工具调用代码路径上搜索出站域名白名单或统一出口
MEM-01  检查记忆模块是否只有按会话隔离的读取路径
AGT-01  检查子代理是否默认继承更小权限、失败是否回传
INJ-01  确认产出物是否引用了工作区外资料、读写之间有无来源标注
SVC-01  读 app.run(...) 一行，确认 host 是 127.0.0.1
SEC-01  统计环境变量中的凭据类变量名（只统计，不读值）
```

输出结构（每个工具按此记录，便于横向比较与复盘）：

```text
[RISK|WARN|OK] 编号 标题
  证据: 可复核的取证结果（文件行 / 运行时声明 / 检出计数）
  影响: 该问题在本实例上具体意味着什么
  处置: 可执行的改进动作
```

纪律：**只读**（不修改文件、不发外部请求）、**不打印凭据值**。

### 4.3 典型判定结果形态

高影响配置的典型样本会命中多数 RISK：文件策略过宽、审批关闭、四类高影响能力齐备、无出口白名单、记忆双路径、委派无审计。这些单独看都可接受，组合即完整攻击链。

## 5. 代码：原理的最小复现

把两项检查写成最小可执行形式——注意 `evidence` 放的是**可复核的原文**，不是结论：

```python
import re

DECLARED = {
    "file_policy": "danger-full-access",
    "approval_prompts": "disabled",
    "shell": "pwsh",
}

def check_policy(declared: dict) -> dict:
    """POL-01/02：文件策略与审批通道。证据 = 运行时声明原文。"""
    risky = declared["file_policy"] != "workspace-write"
    return {
        "id": "POL-01", "level": "RISK" if risky else "OK",
        "evidence": f"file_policy={declared['file_policy']}",
        "impact": "完整文件访问时，读取边界缺失（见 atk-boundary.md）",
        "fix": "改用 workspace-write 并补齐读取侧白名单",
    }

def check_listener(source: str) -> dict:
    """SVC-01：服务监听地址。证据 = 代码行原文。"""
    m = re.search(r'app\.run\(host="([^"]+)"', source)
    if not m:
        return {"id": "SVC-01", "level": "WARN",
                "evidence": "未找到 app.run(...) 调用",
                "impact": "无法判断服务是否仅监听回环地址",
                "fix": "显式声明 host 与 port，并确认绑定 127.0.0.1"}
    host = m.group(1)
    return {
        "id": "SVC-01", "level": "OK" if host == "127.0.0.1" else "RISK",
        "evidence": m.group(0),
        "impact": "仅回环监听时外部网络不可达；0.0.0.0 则暴露给整个网络",
        "fix": "保持 127.0.0.1 绑定；需要对外时前置认证网关",
    }

rows = [check_policy(DECLARED), check_listener(open("web/app.py", encoding="utf-8").read())]
for r in rows:
    print(f"[{r['level']:4}] {r['id']}  证据: {r['evidence']}")
```

三条判定纪律直接体现在代码里：

1. **证据必须可复核**：`evidence` 字段放声明原文或代码行，不放"我认为"。
2. **无法确认记 WARN，不记 OK**：找不到 `app.run(...)` 时输出 WARN 并说明原因，而不是默认安全。
3. **不读凭据值**：涉及环境变量只统计名称与数量。

## 6. 检测与观察点

- 会话中出现"枚举工具面 / 询问权限策略"的提问序列。
- 对配置文件、环境变量、监听端口的批量读取。
- 记忆存储中同时存在隔离与未隔离两条读取路径（代码层信号）。
- 委派调用中子代理权限高于任务所需，或失败无回传。

## 7. 防御与改进

- **最小权限工具集**：按任务授予，四类高影响能力不要默认齐备。
- **审批通道开启**：高影响动作必须人工确认，且确认的是原始动作而非摘要（见 `atk-assemble.md`）。
- **出口白名单 + 统一出口 + 出站日志**：这是链的最后一环，必须独立生效。
- **记忆隔离**：只保留按会话隔离的读取路径，删除未隔离路径。
- **委派审计**：子代理默认继承更小权限集，失败必须回传。
- **监听绑定 127.0.0.1**：管理面不对外。
