# 模型反演

> Model Inversion · 分类：模型与数据层攻击

## 1. 一句话定义

从模型的输出逆推训练数据中的特征或属性：不需要拿到训练集，只靠反复查询就能重建出被训练数据"记住"的信息。

## 2. 机制与原理

- 模型在训练中会把数据的统计特征压缩进参数，这些特征会影响它在相关输入上的输出。
- 攻击者通过观察输出随输入的变化，逐步逼近某些特征值。
- 对于人脸识别、医疗诊断这类以敏感数据训练的系统，被反演出来的往往是具有隐私属性的信息。
- 与成员推断的区别：成员推断回答"这条数据在不在训练集里"，反演回答"训练数据长什么样"。
- 与训练数据提取的区别：提取是逐字还原文本，反演更多是重建特征或类别原型。
- 对应技术：AML.T0024.001（Invert AI Model）。

## 3. 攻击面与前提

| 项 | 内容 |
| --- | --- |
| 入口 | 推理接口、返回置信度或相似度的接口 |
| 成立前提 | 接口可反复查询；输出信息量足够；模型对训练数据存在记忆 |
| 观察点 | 针对同一目标类别的密集查询；对置信度变化的系统性探测 |
| 影响 | 个人隐私泄露；可用于规避原有检测能力 |

## 4. 典型形态与示例

```text
1. 迭代优化
   从一个随机输入出发，反复查询模型并依据输出调整输入
   逐步使模型对该输入给出高置信度的目标判定

2. 置信度利用
   返回的置信度越高，说明输入越接近模型学到的类别原型
   把置信度当作优化目标函数

3. 类别原型重建
   对某个类别反复优化，得到一个能稳定触发该判定的输入

4. 属性推断
   固定部分属性、变化另一部分，观察输出变化以推断敏感属性

5. 与成员推断组合
   先用反演找到接近训练数据的样本，再用成员推断确认是否真的在训练集中
```

## 5. 检测与观察点

- 针对单一类别或单一目标的大量迭代查询。
- 输入空间中出现明显不符合业务分布的样本（优化过程的中间产物）。
- 查询间隔高度规律，符合自动优化循环的节奏。
- 同一来源对置信度变化的探测意图明显。

## 6. 防御与改进

- 限制返回信息量：不提供不必要的置信度、相似度与候选分布。
- 对输出加噪声或做量化处理，降低可被用于优化的信息密度。
- 对查询做速率与配额限制，并对迭代式探测建立检测特征。
- 敏感场景下优先考虑在本地完成推理，减少接口暴露。
- 训练阶段引入差分隐私等手段，从源头降低记忆强度。
