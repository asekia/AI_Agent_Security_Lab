# 模型反演

> Model Inversion · 分类：模型与数据层攻击

## 1. 问题与威胁模型

**定义**：从模型输出逆推训练数据中的属性或特征，恢复不应暴露的信息。
**威胁模型**：攻击者能对目标模型做定向查询；模型对特定输入返回置信度或完整输出。
**命题**：模型记住了训练分布的特征——反复查询边界即可重建属性。

**威胁模型**：

| 角色 | 能力 |
| --- | --- |
| 攻击者 | 按本节前提访问接口或数据 |
| 目标 | 按本节定义的模型/索引/训练流程 |
| 前提 | 见攻击面表 |

## 2. 攻击面与前提

| 项 | 内容 |
| --- | --- |
| 入口 | 见实战步骤 |
| 前提 | 见步骤注释 |
| 观察点 | 输入输出差异、记忆强度、召回结果 |
| 影响 | 能力窃取、隐私泄露、行为偏移 |

## 3. 实战步骤

**步骤 1**：确定目标属性（某个体的性别、年龄、健康状态）。
**步骤 2**：构造候选输入并查询，记录输出分布。
**步骤 3**：按输出置信度排序，选最可能命中的候选。
**步骤 4**：人工核验候选与真实属性的相关性。
**步骤 5**：判定：恢复的属性显著优于随机猜测 = 反演成功。

## 5. 检测与取证

- 查询/写入模式异常（批量、分布外、定向）。
- 输出侧可复核证据（原文、置信度、召回记录）。
- 取证：请求日志、响应样本、索引快照。

## 6. 防御与验证

1. 限制置信度输出精度。
2. 对定向查询做频次与模式检测。
3. 训练时做差分隐私。
4. 高风险属性不进入训练数据。

**验证**：按本页步骤复跑，确认目标行为消失。
