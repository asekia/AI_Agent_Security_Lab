# 向量与嵌入弱点

> Vector & Embedding Weaknesses · 分类：模型与数据层攻击

## 1. 问题与威胁模型

**定义**：向量库访问控制缺失、索引污染、跨租户检索与嵌入反演。
**威胁模型**：攻击者可写入索引或读取向量库；检索不按租户隔离。
**命题**：向量库是 RAG 的"记忆"，污染它等于污染所有检索结果。

**威胁模型**：

| 角色 | 能力 |
| --- | --- |
| 攻击者 | 按本节前提访问接口或数据 |
| 目标 | 按本节定义的模型/索引/训练流程 |
| 前提 | 见攻击面表 |

## 2. 攻击面与前提

| 项 | 内容 |
| --- | --- |
| 入口 | 见实战步骤 |
| 前提 | 见步骤注释 |
| 观察点 | 输入输出差异、记忆强度、召回结果 |
| 影响 | 能力窃取、隐私泄露、行为偏移 |

## 3. 实战步骤

**步骤 1**：确认索引写入权限与来源审核。
**步骤 2**：植入权威口吻文档，测试是否被优先召回。
**步骤 3**：跨租户查询测试：用 A 的查询检索 B 的内容。
**步骤 4**：判定：投毒文档被召回或跨租户内容可见 = 弱点成立。

## 5. 检测与取证

- 查询/写入模式异常（批量、分布外、定向）。
- 输出侧可复核证据（原文、置信度、召回记录）。
- 取证：请求日志、响应样本、索引快照。

## 6. 防御与验证

1. 索引写入审核与来源签名。
2. 按租户命名空间强制隔离。
3. 召回结果做来源与权限过滤。
4. 定期审计索引内容。

**验证**：按本页步骤复跑，确认目标行为消失。
