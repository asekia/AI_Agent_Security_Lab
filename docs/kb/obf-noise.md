# 噪声分级与比例控制

> Noise Tiers & Ratios · 分类：编码混淆与扰动

## 1. 一句话定义

对控制语句施加字符级扰动，用少量噪声破坏关键词匹配，同时保持语义仍可被模型读出。噪声越多越容易规避检测，也越可能被模型误读，因此需要一个可调的"比例"。

## 2. 机制与原理

- 基于关键词与正则的检测依赖字符的连续匹配；在词内插入干扰字符就能破坏匹配。
- 模型对轻微扰动的鲁棒性远高于正则表达式：插入零宽字符或空格后，人眼看上去近似原文，模型仍能还原原意。
- 噪声比例是关键参数。太少不能规避检测，太多会改变语义或被模型当作乱码忽略。
- 三级噪声强度：
  - Phase A 轻度：只在少量关键词插入轻度干扰，可读性最好。
  - Phase B 中度：在多个关键词插入干扰，兼顾规避与可读。
  - Phase C 重度：大范围扰动，规避能力最强，语义风险也最高。

## 3. 攻击面与前提

| 项 | 内容 |
| --- | --- |
| 入口 | 用户输入、被检索文档、长期驻留内容 |
| 成立前提 | 检测依赖字符串匹配；模型能还原被扰动文本 |
| 观察点 | 异常字符密度、字符类别混杂、不可见字符 |
| 影响 | 绕过关键词过滤，载荷进入模型上下文 |

## 4. 典型形态与示例

```text
比例档位（按被扰动字符占比估算）
  10% —— 轻量试探，观察是否被拦截
  20% —— 常规起点
  30% —— 规避效果明显，可读性开始下降
  35% —— 上限附近，继续增加收益递减，且更容易被识破

调参方法
  固定母句不变，逐档提高噪声比例
  记录"哪一档开始能通过检测，同时仍被正确理解"
  找到该档位后不再继续加噪，避免语义漂移
```

```text
干扰字符的常用选择
  零宽字符：在词内插入不可见字符
  空白符号：普通空格、不换行空格、窄空格
  标点穿插：在词内插入点号、连字符、斜杠
  换行切割：把关键词从中间断开
```

## 5. 检测与观察点

- 文本中不可见字符与非常规空白的密度。
- 同一文档内字符集混杂（拉丁字母与西里尔、希腊字母混排）。
- 关键词被非常见字符打断的规律性（同一位置反复出现）。
- Unicode 归一化后内容与原始内容差异巨大的文档。

## 6. 防御与改进

- 输入先做 Unicode 归一化与不可见字符剥离，再进入检测流程。
- 检测在归一化后的文本上进行，而不是在原始字节上。
- 对高噪声文本单独分流，交由人工或更强模型复核。
- 把噪声特征本身作为风险信号记录与告警，而不是简单放行。
