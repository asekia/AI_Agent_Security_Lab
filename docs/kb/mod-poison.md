# 数据投毒与后门

> Data Poisoning & Backdoors · 分类：模型与数据层攻击

## 1. 问题与威胁模型

**定义**：在训练/微调/嵌入数据中植入错误关联或触发式后门，使模型在特定条件出现恶意行为。
**威胁模型**：攻击者可影响数据来源、标注流程或微调数据集。
**命题**：投毒在训练期完成，验证集未必包含触发模式，因此可"通过所有验证"。

**威胁模型**：

| 角色 | 能力 |
| --- | --- |
| 攻击者 | 按本节前提访问接口或数据 |
| 目标 | 按本节定义的模型/索引/训练流程 |
| 前提 | 见攻击面表 |

## 2. 攻击面与前提

| 项 | 内容 |
| --- | --- |
| 入口 | 见实战步骤 |
| 前提 | 见步骤注释 |
| 观察点 | 输入输出差异、记忆强度、召回结果 |
| 影响 | 能力窃取、隐私泄露、行为偏移 |

## 3. 实战步骤

**步骤 1**：选入口（公开数据集、标注外包、微调样本、嵌入文档）。
**步骤 2**：植入触发模式（特定短语/格式）+ 目标行为。
**步骤 3**：混合比例控制在可被验证集忽略的范围。
**步骤 4**：验证：留出集中构造触发输入，观察目标行为。
**步骤 5**：判定：触发条件下行为显著偏离 = 后门成立。

## 5. 检测与取证

- 查询/写入模式异常（批量、分布外、定向）。
- 输出侧可复核证据（原文、置信度、召回记录）。
- 取证：请求日志、响应样本、索引快照。

## 6. 防御与验证

1. 数据来源审核与签名。
2. 标签质量抽检与异常检测。
3. 留出集含触发模式测试。
4. 模型注册表签名与审计。

**验证**：按本页步骤复跑，确认目标行为消失。
