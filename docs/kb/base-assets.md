# AI 资产面与威胁总表

> AI Asset Surface & Threat Table · 分类：基础与威胁建模

## 1. 问题与定位

AI 系统的资产不止模型权重。把资产拆成六类，才能逐类回答"谁能写、谁能读、被改了会怎样"。

## 2. 六类核心资产

| 资产 | 作用 | 被破坏的后果 | 关键控制 |
| --- | --- | --- | --- |
| 训练数据 | 决定模型行为模式 | 投毒深入模型本身，需重新训练 | 来源审核、去重、留出集 |
| 模型权重 | 学到的参数 | 窃取即复制、后门即植入 | 访问控制、加密、签名 |
| 嵌入向量 | 检索与推荐的基础 | 污染影响召回与下游判断 | 索引写入审核、租户隔离 |
| 系统提示 | 行为与安全规则 | 泄露规则、便于定向绕过 | 结构保护、泄露检测 |
| 特征/工具描述 | 推理输入与能力契约 | 篡改改变"感知"与可用动作 | schema 校验、来源签名 |
| 模型注册表 | 版本与制品谱系 | 替换为后门版本且通过验证 | 签名、审计、拒绝同名覆盖 |

## 3. 威胁总表

| 资产 | 主要威胁 | 攻击入口 | 可利用后果 |
| --- | --- | --- | --- |
| 训练数据 | 投毒、后门 | 公开数据集、标注流程 | 触发词行为 |
| 模型权重 | 窃取、逆向、替换 | API、注册表、制品桶 | 模型复制、后门 |
| 嵌入向量 | 索引污染、跨租户检索 | 向量库写入接口 | 错误召回、数据泄露 |
| 系统提示 | 泄露、篡改 | 对话套取、插件替换 | 规则暴露、绕过 |
| 工具描述 | 投毒、越权声明 | MCP server、插件市场 | 工具误用、凭证读取 |
| 注册表 | 制品替换、谱系伪造 | 未认证注册接口 | 供应链后门 |

## 4. 实战：资产清点五步

### 步骤 1：列资产

```text
按六类逐项填写：位置、格式、写入者、读取者、保留期限
```

### 步骤 2：标信任边界

```text
哪些资产可被外部写入（公开 bucket、共享索引、插件描述）
哪些资产只有内部能写（权重、注册表）
```

### 步骤 3：查控制

```text
每一类资产问三句：谁能写？写入留痕吗？被改后多久能发现？
```

### 步骤 4：排优先级

```text
外部可写 + 无留痕 + 影响面大 = 最高优先级
```

### 步骤 5：落到整改

```text
每个高风险资产至少补一条硬约束：签名、白名单、审核、隔离
```
